🤖 자동주문
🤖증권사 Open API 자동주문 · 설치와 안전장치

어떻게 도나: 내 GitHub 비공개 저장소(muhan-bot)의 Actions가 매일 미국 정규장 중(한국 00:10 무렵, 예비 02:10)에 이 앱을 클라우드에서 그대로 열어 동기화된 기록·설정으로 오늘의 LOC를 계산하고, 검수 8단계를 통과한 주문만 증권사 Open API로 LOC 접수합니다. 결과는 🔌 자동주문(해외) 앱과 ⚡ 주문 탭 맨 위에 모든 기기 공통으로 표시됩니다. 폰·PC를 켜 둘 필요가 없습니다.

준비 (한 번): ① ☁️ 동기화에 쓰는 GitHub 토큰(classic)에 repo · workflow 권한을 추가합니다 — github.com → Settings → Developer settings → Personal access tokens → Tokens (classic) → 기존 토큰 클릭 → repo·workflow 체크 → Update token (토큰 값은 그대로라 다시 붙여넣을 필요 없음). ② 무한매수 허브 맨 위 🔌 자동주문(해외) 앱에서 [봇 설치] → [앱키 등록] → [🔧 연결 점검] → [⚡ 지금 실전 주문] 또는 매일 자동 [실전]. 봇 프로그램은 그 앱(api.html) 안에 들어 있어 api.html 만 새 버전으로 올리면 다음 실행 때 봇도 자동으로 업데이트됩니다.

앱키 보관: App Key·Secret은 입력하는 순간 GitHub 공개키로 봉인 암호화되어 저장소 금고(Actions Secrets)로만 갑니다. 이 기기·Gist·백업 어디에도 남지 않고 GitHub에서도 되읽을 수 없습니다. 한 번 등록하면 봇이 계속 쓰고, 어느 기기에서든 새 키로 교체할 수 있습니다.

검수 8단계 (하나라도 어긋나면 그 주문은 내지 않음): V1 계획이 최신(직전 거래일 종가 기준) · V2 같은 공식으로 가격·수량 재계산 일치 · V3 증권사 일봉 종가와 앱 종가 대조 · V4 실제 계좌 보유 수량 = 앱 기록 · V5 주문가능금액 ≥ 매수금액 · V6 매도가능수량 ≥ 매도수량 · V7 매수 1건 한도 · V8 같은 주문 중복 방지. 접수 뒤에는 당일 주문내역을 다시 읽어 종목·매매·LOC·수량·가격을 대조하고, 다르면 즉시 취소합니다. 증권사가 경고(착오매매 등)를 주면 자동으로 확인하지 않고 멈춥니다.

예: 평단 $30.1234 · 전일 종가 $29.875 · 1분할 $8,850 → 매수 = min(평단, 종가) 센트 내림 $29.87 × (8,850÷29.87 = 296 → 1주 단위) 296주, 매도 = 30.1234 × 1.08 센트 올림 $32.54 × 보유 200주. 앱 계획과 봇 검산이 한 푼이라도 다르면 차단됩니다.

문제가 생기면: [🔧 연결 점검]이 증권사 토큰·해외 잔고·주문가능금액·당일 주문·SOXL/QLD 시세·앱 주소를 하나씩 확인해, 막힌 곳과 고칠 방법(증권사 공식 응답 코드 기준 — 예: EGW00103 앱키 오류, 0760 해외주식 권한 없음)을 보여 줍니다. 봇이 결과를 남기지 못하고 멈춰도 ‘GitHub 실행’ 줄에 멈춘 단계와 로그 링크가 뜹니다.

모드: 끄기 · 리허설(매일 검수만, 주문 안 냄) · 실전. 실전은 최근 7일 안에 리허설이 통과해야 켜지고, 두 번 눌러야 전환됩니다. 결과가 ⛔면 GitHub가 메일로도 알려 주며, ntfy 주제를 넣으면 폰 푸시가 옵니다.

AI(MCP)로 확인: 증권사 공식 MCP 서버(github.com/meritz-securities/open-api-mcp)를 조회 전용으로 Claude에 연결하면 "오늘 SOXL 주문내역 보여줘"처럼 대화로 검수할 수 있습니다. 증권사는 MCP를 무인 자동주문에 쓰지 말라고 안내하므로, 주문은 이 봇이, 확인은 AI가 맡습니다.

수수료·세금·환율은 반영하지 않으며, 투자 판단과 결과의 책임은 본인에게 있습니다.

⚡ 주문 탭
⚡오늘의 LOC 주문
📒나의 매수 기록

실제 매수 내역을 입력해 누적 평단가를 계산합니다. 매수 수량을 비워두면 1분할 금액(시드 ÷ 분할 수) ÷ 매수가를 1주 단위로 내림한 수량(LOC 가이드와 같은 공식)이 자동으로 들어갑니다. 매수 날짜는 어제(가장 최근 확정 종가일)가 기본으로 들어갑니다. 시세를 불러왔을 때 어제 종가가 LOC 매수가 이하였으면(체결 조건 충족) 저장 버튼을 누르지 않아도 그 매수가 자동으로 기록됩니다. 매수가를 비워두면 입력한 매수일의 QLD 종가를 자동으로 채웁니다(주말·휴장일은 직전 거래일 종가, 오늘 장중이면 실시간 현재가). 이 기록은 이 브라우저(로컬 저장소)에만 저장되며 서버로 전송되지 않으므로, 다른 기기·브라우저에서는 보이지 않습니다.

🏁 사이클 탭
🏁사이클 기록

사이클 = 첫 매수부터 전량 매도까지. 익절이든 손절이든 보유 전량을 매도하면 그 사이클이 끝나고, 매도일 기준으로 연도.순번차 이름이 자동으로 붙습니다. 예: 2026년에 세 번째로 끝난 사이클 = 2026.3차. 해가 바뀌면 2027.1차부터 다시 셉니다.

자동 종료(익절): 시세를 불러올 때 마지막 기록 다음 거래일부터 어제까지 하루씩 다시 계산해, 그날 종가가 LOC 매도 예약가(평단 × (1 + AI 익절%), 센트 올림) 이상이면 보유 전량을 그날 종가로 매도한 것으로 보고 사이클을 닫습니다. 그다음 거래일부터는 신규 진입(전일 종가 이하 LOC)을 다시 자동 기록합니다. 손절·직접 매도는 LOC 주문이 없으므로 [사이클 종료 직접 기록]에 날짜와 매도가를 넣으면 같은 방식으로 닫힙니다(매도가를 비우면 그날 종가).

사이클마다 남는 기록: 기간(첫 매수 → 매도, 달력 일수·거래일 수), 매수 횟수와 분할 사용(예: 4/8), 수량·평단·투입금, 매도가, 손익 금액, 수익률, 보유 중 최대 낙폭(그 사이 최저 종가 ÷ 평단 − 1), 자동·직접 구분, 그 사이클의 매수 내역. 예: 9/24 → 9/30 · 6일 · 매수 2회 · 평단 $49.50 → $70.00 · +$2,050 · +41.41%.

평생 요약: 누적 손익과 실현 수익률(손익 합계 ÷ 투입금 합계), 승률(익절 ÷ 전체), 평균 기간, 평균 매수 횟수, 최고·최저 사이클, 연도별 소계. 수수료·세금·환율은 반영하지 않습니다.

평생 보관: 기록은 이 기기에 저장되고, ☁️ 동기화를 켜면 사이클이 끝날 때마다 GitHub 비공개 Gist에 자동으로 올라갑니다. 앱 데이터와 함께 QLD-cycles.md 라는 읽기 좋은 표 문서도 매번 다시 써지므로, 앱이 없어도 GitHub에서 기록을 볼 수 있습니다. 📊 엑셀 내보내기에도 사이클 시트가 들어갑니다. 잘못 닫힌 사이클은 줄을 펼쳐 [이 사이클 삭제]를 누르세요(가장 최근 것이면 매수 기록이 되살아납니다).

💾 백업 탭
☁️PC · 모바일 기록 동기화

매수·매도·수익 기록을 내 GitHub 계정의 비공개(secret) Gist 한 곳에 저장해 PC와 폰이 같은 기록을 씁니다. 화면을 열 때, 기록을 저장·삭제할 때(1.5초 뒤), 다른 앱에서 돌아올 때, 열어둔 동안 90초마다 자동으로 맞춥니다.

토큰 만들기 (한 번만): github.com → 오른쪽 위 프로필 → Settings → 맨 아래 Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic) → Note: 무한매수 동기화, Expiration: No expiration(또는 1년), 권한은 gist 하나만 체크 → Generate → ghp_… 복사. 같은 토큰을 PC와 폰의 이 카드에 각각 한 번씩 붙여넣고 [연결]을 누르면 끝입니다. SOXL에서 연결하면 같은 기기의 QLD도 자동으로 연결됩니다.

합치는 규칙: 처음 연결하면 PC 기록과 폰 기록을 합칩니다(백업 복원으로 옮긴 같은 기록은 1건으로 인식). 한쪽에서 지운 기록은 다른 쪽에서도 지워지고, 두 기기가 같은 날 자동 저장한 체결은 1건으로 합칩니다. 양쪽에 같은 매수를 손으로 따로 입력했다면 2건이 되니 하나를 지우세요. 인터넷이 끊겨도 이 기기에 먼저 저장되고, 연결되면 자동으로 올라갑니다.

보안: 토큰은 이 기기 브라우저에만 저장되며 백업 텍스트에도 포함되지 않습니다. gist 권한만 있어 저장소·계정은 건드릴 수 없습니다. 비공개 Gist는 검색되지 않지만 주소를 아는 사람은 볼 수 있으니 Gist 주소는 공유하지 마세요. 폰을 잃어버리면 GitHub에서 토큰을 삭제(Revoke)하면 됩니다.

🤖 AI엔진 탭
🤖QLD 변동성 최적화 AI 엔진

기본 파라미터(6분할 · 2단계 주기 14일 · 손절모드 -12% — V0.72부터 2단계는 주기 대신 ×3 분할 연속 매수)는 QLD 평상시 일간σ 약 2.4%에 맞춰져 있습니다. 이 엔진은 조회 시점 QLD의 실제 일간σ를 측정해 ① 변동성 배율로 파라미터를 환산한 "규칙 기반 추천"과 ② 분할 수(2단계는 대기 없이 ×3 고정) 조합을 최근 200봉에 전수 백테스트해 인접 조합 평균(과최적화 완화)이 가장 높은 "백테스트 최적"을 함께 제시합니다. 백테스트는 아래 시뮬레이션과 같은 "평단&전일종가 이하" 매수 규칙을 사용하며, 버튼을 누르면 시뮬레이션과 LOC 가이드에 바로 적용됩니다.

🌊QLD·QQQ 변동성 프로파일

최근 200봉 QLD 일간 수익률의 변동성(표준편차)과 최근 20봉 변동성을 비교해 현재 변동성 국면을 진단합니다. 손절모드 기준선을 변동성 국면에 맞게 보정한 참고선과, 오늘 종가 기준 1σ 예상 등락 범위도 함께 제시합니다.

🎯 가이드 탭
🎯LOC 매수/매도 예약 가이드

다음 LOC(지정가-종가) 매수/매도 예약 가격과 수량을 계산합니다. 매수 예약가는 "평단 & 전일종가 이하" 기준(시드 분할매수 시뮬레이션의 매수 조건)으로, 평단가와 전일 확정 종가 중 더 낮은 값을 사용합니다. 두 가격 이하로 마감해야만 체결되므로 평단 위에서 물타기가 되는 일을 막아줍니다. 보유 수량이 없는 신규 진입 시에는 평단가가 없어 전일 확정 종가만 적용합니다. 시드·분할 수·2단계 분할 배수는 시뮬레이션의 입력값을, 매수 회차·단계 판정은 "나의 매수 기록"의 실제 내역을 사용합니다.

🧪시드 분할매수 시뮬레이션 [평단&전일종가 이하] (최근 200봉)

시드를 N분할해 최근 200봉에 적용한 시뮬레이션입니다. 매수 규칙: ① 종가가 전일 종가보다 낮은 날 1분할 최초 매수, ② AI 추천 분할매수 회차까지는 이후 종가가 현재 평단보다 낮으면서 전일 종가보다도 낮은 날마다 1분할씩 추가 매수, ③ AI 추천 회차를 초과하면(2단계) 기다리지 않고 같은 조건이 맞는 날마다 시드÷(분할×배수, 기본 ×3)씩 추가 매수 — 예) 9분할·추천 5회면 1단계 5회 × 시드/9 + 2단계 최대 12회 × 시드/27 = 시드 전액(총 17회). 매도 규칙: 평단가 대비 목표% 도달 시 익절(아래 비교 익절(%)에 원하는 값을 넣으면 같은 규칙으로 익절%만 바꾼 결과를 나란히 보여주고, 주변 익절% 몇 개의 시드 대비 수익률도 함께 표시합니다), 시드를 모두 쓴 뒤(최대 회차) 손절선에 닿으면 손절합니다. 포지션은 한 번에 하나만 운용하며 청산 다음 거래일부터 새 진입을 탐색합니다.

📊 통계 탭
📉QLD 연속 하락 통계 (최근 200봉)

최근 200봉 종가 기준 연속 하락 일수별 발생 확률과, 연속 하락 시마다 종가로 1주씩 매수하여 하락 전 고점 가격에 도달했을 때 전량 매도했다고 가정한 구간별 평균 수익률입니다. 상단 요약의 평균 연속일수·평균 하락률·최대 하락률은 실제 발생한 모든 연속 하락 구간을 집계한 값이며, 평균 하락률은 최대·최소 각 1건을 제외하고 계산합니다.

📈QLD 연속 상승 통계 (최근 200봉)

최근 200봉 종가 기준 연속 상승 일수별 발생 확률과, 연속 상승 구간별 평균 상승률입니다. 상승률은 상승 시작 전 종가(직전 저점) 대비 상승 종료일 종가의 변화율입니다. 상단 요약의 평균 연속일수·평균 상승률·최대 상승률은 실제 발생한 모든 연속 상승 구간을 집계한 값이며, 평균 상승률은 최대·최소 각 1건을 제외하고 계산합니다.

HOW IT WORKS

설명

⚡ 하는 일 (딱 두 가지)

① 증권사 실제 주문내역을 조회해 같은 종목·매매 주문이 이미 있으면 🔁 중복으로 표시하고 끝. ② 없으면 ⚡ 주문 탭에서 고른 주문코드로 바로 실제 주문합니다. 장 시간은 따지지 않습니다 — 증권사가 거부하면 그 이유를 풀어 🧾 결과·텔레그램으로 알려 드립니다.

⏰ 언제 · 어디서

내 GitHub 비공개 저장소의 Actions(클라우드)에서 정한 시각에 돕니다(허브·폰을 꺼 둬도 됨). 안 되면 설정한 간격·횟수로 다시 실행하고, cron-job.org를 쓰면 정확한 시각에 실행됩니다. 미국 휴장일은 건너뜁니다.

💲 가격·수량

앱 계획(같은 코드·같은 동기화 기록)에서 자동 입력합니다. 시장가 계열(05·33·34·37·38)은 단가 0. ☑매도는 계좌 매도가능 수량 전량.

🔐 보안

앱키·시크릿은 GitHub 금고(Actions Secrets)에만 봉인 저장됩니다(이 기기·Gist·백업에 남지 않음). 봇 저장소는 반드시 비공개여야 합니다.

📒 탭 구성

QLD 탭은 QLD 무한매수 앱의 ‘주문·사이클’ 화면을 그대로 띄웁니다(매수 기록 · 오늘의 LOC · 사이클 기록 · 엑셀). AI 분석(엔진·가이드·통계)은 허브의 QLD 무한매수AI분석 앱에서 봅니다. 수수료·세금·환율은 반영하지 않으며 투자 판단과 결과의 책임은 본인에게 있습니다.
