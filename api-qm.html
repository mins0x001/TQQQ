HOW IT WORKS

설명

⚡ 하는 일 (딱 두 가지)

① 메리츠 실제 주문내역을 조회해 같은 종목·매매 주문이 이미 있으면 🔁 중복으로 표시하고 끝. ② 없으면 ⚡ 주문 탭에서 고른 주문코드로 바로 실제 주문합니다. 장 시간은 따지지 않습니다 — 메리츠가 거부하면 그 이유를 풀어 🧾 결과·텔레그램으로 알려 드립니다.

⏰ 언제 · 어디서

내 GitHub 비공개 저장소의 Actions(클라우드)에서 정한 시각에 돕니다(허브·폰을 꺼 둬도 됨). 안 되면 설정한 간격·횟수로 다시 실행하고, cron-job.org를 쓰면 정확한 시각에 실행됩니다. 미국 휴장일은 건너뜁니다.

💲 가격·수량

앱 계획(같은 코드·같은 동기화 기록)에서 자동 입력합니다. 시장가 계열(05·33·34·37·38)은 단가 0. ☑매도는 계좌 매도가능 수량 전량.

🔐 보안

앱키·시크릿은 GitHub 금고(Actions Secrets)에만 봉인 저장됩니다(이 기기·Gist·백업에 남지 않음). 봇 저장소는 반드시 비공개여야 합니다.

📒 탭 구성

QLD 탭은 QLD 무한매수 앱의 ‘주문·사이클’ 화면을 그대로 띄웁니다(매수 기록 · 오늘의 LOC · 사이클 기록 · 엑셀). AI 분석(엔진·가이드·통계)은 허브의 QLD 무한매수AI분석 앱에서 봅니다. 수수료·세금·환율은 반영하지 않으며 투자 판단과 결과의 책임은 본인에게 있습니다.
