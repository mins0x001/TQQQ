HOW IT WORKS

설명

🇰🇷 LOC 대신 종가 단일가

국내 ETF에는 LOC 주문이 없습니다. 봇은 15:20~15:30 종가 단일가 시간에 오늘의 가격으로 지정가 주문을 냅니다. 15:30에 정해지는 종가가 매수 지정가 이하(매도는 이상)면 그 종가로 체결 → 미국 LOC와 결과가 같습니다. 예) 매수 지정가 75,595원 · 15:30 종가 75,000원 → 75,000원에 체결 / 종가 76,000원 → 체결 안 됨. 주문은 KRX로만 보냅니다(NXT에는 종가 단일가가 없음).

⏰ 언제 · 어디서 도나

내 GitHub 비공개 저장소 muhan-bot-kr(해외 봇과 별도)의 Actions(클라우드)에서 돕니다. 허브·앱·폰을 꺼 둬도 됩니다. 평일 14:45에 시작해 계좌·체결을 맞추고, 이 앱(kodex.html)을 클라우드에서 그대로 열어 오늘 주문을 계산·검수한 뒤 15:20까지 기다렸다 접수합니다. GitHub 예약 실행은 붐비면 늦거나 빠질 수 있어 14:57 · 15:09 · 15:36에 예비 실행이 있습니다(이미 낸 주문은 다시 내지 않음). 종가 단일가를 놓치면 장후 시간외 종가(15:40~16:00)로 넘어가, 오늘 종가가 LOC 조건에 맞을 때만 종가로 주문합니다. 국내 휴장일과 수능일 같은 시각 변경은 메리츠 영업일·장운영 조회로 자동 반영됩니다. 16:12에는 계좌·체결을 읽어 매수 기록·사이클 기록을 자동으로 맞춥니다.

💲 가격·수량

가격·수량은 K반도체레버리지 AI분석 앱을 이 화면 안에서 그대로 실행해 받은 값입니다(같은 코드 · 같은 동기화 기록). 호가단위는 5원(2,000원 이상 ETF)이라 매수가는 5원 단위 내림, 매도가는 5원 단위 올림입니다. ☑매수는 규칙상 매수 없음이어도 같은 공식으로 주문하고(2단계는 시드÷(분할×3)씩), ☑매도는 주문 직전 계좌 보유 수량 전량을 다시 읽어 그 수량으로 냅니다.

🛡 검수

V1 계획 최신(직전 영업일 종가) · V2 같은 공식 재계산 · V3 메리츠 기준가(전일 종가) 대조 · V4 계좌 보유 = 앱 기록 · V5 주문가능금액 · V6 매도 = 보유 전량 · V7 매수 1건 한도 · V8 같은 날 같은 매매 중복 방지(MTS 주문·예약주문 포함) · V9 호가단위·상하한가. 접수 직후 당일 주문내역을 다시 읽어 대조하고, 다르면 즉시 취소합니다. 메리츠 경고는 자동으로 확인하지 않습니다.

🔐 계좌 · 보안

해외 자동주문과 다른 메리츠 계좌의 앱키를 써도 됩니다 — 이 앱의 앱키는 muhan-bot-kr 저장소 금고(Actions Secrets)에만 봉인 저장되고, 해외 봇(muhan-bot)의 키와 섞이지 않습니다. 기록 동기화(☁️ Gist)는 SOXL·TQQQ와 같은 것을 쓰되 파일이 따로입니다(muhan-bot-kr.json · muhan-bot-kr-status.json · muhan-account-kr.json). 봇 저장소는 반드시 비공개여야 합니다.

수수료·세금은 반영하지 않으며 투자 판단과 결과의 책임은 본인에게 있습니다.
