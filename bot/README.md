이 저장소는 무한매수 앱의 🤖 카드 **[봇 설치]** 가 만들었습니다. 설정은 앱에서 바꾸세요 — 여기서 고칠 것은 없습니다.

## 매일 하는 일 (월~금, 한국 00:10 · 예비 02:10)
1. **계획** — 무한매수 앱을 클라우드에서 그대로 열어, 동기화된 기록·설정으로 오늘의 LOC를 계산 (앱 화면과 같은 코드)
2. **검수 8단계** — 하나라도 어긋나면 그 주문은 내지 않음

   | | 확인 내용 |
   |---|---|
   | V1 | 계획이 최신 (직전 미국 거래일 종가 기준) |
   | V2 | 같은 공식으로 가격·수량 재계산 → 앱 값과 완전 일치 |
   | V3 | 메리츠 일봉 종가 ↔ 앱 종가 (0.3% 이내) |
   | V4 | 실제 계좌 보유 수량 = 앱 매수 기록 |
   | V5 | 주문가능금액(USD) ≥ 매수금액 |
   | V6 | 매도가능수량 ≥ 매도수량 |
   | V7 | 매수 1건 한도 (앱에서 설정 · 매도는 보유 전량이라 V4·V6로 확인) |
   | V8 | 같은 종목·매매 LOC가 이미 있으면 다시 내지 않음 |
3. **주문** — 해외주식 LOC (`oder_cls_code "32"`, `oder_cond_cls_code "7"`). 메리츠 경고(`warn_cls_code ≠ "0"`)는 자동 확인하지 않음
4. **대조** — 당일 주문내역을 다시 읽어 종목·매매·LOC·수량·가격 확인 → 다르면 즉시 취소
5. **보고** — 동기화 Gist `muhan-bot-status.json` → 앱 🤖 카드·⚡ 주문 탭에 표시. 차단·오류면 이 실행이 실패로 끝나 GitHub 메일이 옵니다
